# Segurança no MCP Dev Lab

## Regras iniciais

- operar somente em modo leitura
- não alterar arquivos automaticamente
- não apagar arquivos
- não executar comandos destrutivos
- não acessar arquivos `.env`
- não acessar chaves SSH ou credenciais
- não fazer `git push`
- não alterar a branch `main`
- revisar manualmente qualquer sugestão da IA

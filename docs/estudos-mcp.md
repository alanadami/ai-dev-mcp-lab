# Estudos sobre MCP

## O que é MCP

MCP significa Model Context Protocol.

É um protocolo que permite conectar assistentes de IA a ferramentas externas, arquivos, repositórios, bancos de dados e APIs de forma padronizada.

## Objetivo no laboratório

Usar MCP para criar uma camada local de consulta e análise de projetos de código.

No primeiro momento, o foco será apenas leitura, estudo e revisão, sem alteração automática de arquivos.

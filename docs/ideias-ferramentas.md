# Ideias de Ferramentas MCP

## Fase 1 — Consulta

- ler documentação do projeto
- listar repositórios configurados
- consultar estrutura de pastas
- buscar arquivos importantes
- identificar tecnologias usadas
- explicar funcionamento geral do projeto

## Fase 2 — Git

- verificar branch atual
- listar arquivos alterados
- ler diff
- listar últimos commits
- sugerir mensagem de commit

## Fase 3 — Revisão

- gerar checklist pré-PR
- comparar código com specs
- apontar pendências
- identificar riscos da alteração
